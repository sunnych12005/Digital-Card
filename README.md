# כרטיס ביקור דיגיטלי - מטלה 1

אתר אישי בעברית ב־HTML ו־CSS בלבד. קובץ הכניסה הוא `index.html`; כל העיצוב נמצא ב־`style.css`. מצב בהיר/כהה ממומש בעזרת checkbox ובוררי CSS, ללא JavaScript.

## התאמה לפני הגשה

המטלה מאפשרת פרטים בדויים, אך כדאי לעדכן את הפרטים הבאים כדי שהכרטיס יציג דרך אמיתית ליצור איתך קשר:

1. קישור ה־LinkedIn פותח את דף הבית של LinkedIn כי אין לך פרופיל אישי. **זה אינו עומד בדרישה המפורשת לקישור לפרופיל LinkedIn שלך.** אם תיצור פרופיל, החלף את שתי ההופעות של `https://www.linkedin.com/` בכתובת הפרופיל.
2. כתובת המייל `sunny@example.com` ומספר הטלפון `050-000-0000` הם פרטי דוגמה, המותרים לפי הוראות המטלה. כדי שיפנו אליך באמת, החלף אותם יחד עם ערכי `mailto:` ו־`tel:`. פרטי הקשר האישיים מקורות החיים לא נכללו באתר הציבורי.
3. אפשר להחליף את `assets/profile.svg` בתמונת פרופיל שלך; התמונה המצורפת היא איור ולא צילום אישי.
4. קישור ה־GitHub באתר כבר מצביע אל `https://github.com/sunnych12005`.

## בדיקה מקומית

פתח את `index.html` בדפדפן. בדוק ניווט, קישורים, מצבי תצוגה ומסך צר בעזרת כלי המפתחים. כל קובצי האתר מקומיים, ואין צורך בהתקנת חבילות או בשרת.

## העלאה והגשה

1. צור Repository **ציבורי** בחשבון GitHub שלך והעלה לשורש המאגר את `index.html`, `style.css` ואת תיקיית `assets`.
2. ב־**Settings → Pages**, בחר **Deploy from a branch**, ענף `main` ותיקייה `/ (root)`, ואז שמור.
3. פתח את כתובת האתר ש־GitHub Pages מציג, וודא שהיא עובדת גם בחלון פרטי. אם בחרת שם מאגר כגון `digital-card`, הכתובת תהיה בדרך כלל `https://sunnych12005.github.io/digital-card/`.
4. במודל צרף **שני קישורים נפרדים**: כתובת המאגר וכתובת האתר החי, וכן את קובץ ה־ZIP של הפרויקט. ההגשה היא אישית בלבד.

שים לב: הדרישה לקישור לפרופיל LinkedIn אישי לא מתקיימת כל עוד הקישור מוביל לדף הבית.
